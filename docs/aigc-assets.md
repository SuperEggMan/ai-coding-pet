# AIGC 资产规格书

给「用 AI 生成 2D 图 / 3D 模型」这条路准备的接入契约。
照这份规格产出资产，放进 `src/skins/<你的皮肤名>/`，`AICP_SKIN=<皮肤名> npm start` 就能换上，**不用改一行代码**。

---

## 0. 先明确引擎替你做了什么

这决定了你**不需要**让 AI 生成什么，能省掉大量返工。

| 你只需要提供 | 引擎负责 |
|---|---|
| 每个状态**一张静态图**（或一个 3D 模型 + 动画片段名） | 状态之间的**过渡插值**：交叉淡入淡出 + 整体位姿补间 |
| —— | **待机循环**：呼吸、轻微起伏、抖动，由 `loops` 描述，作用在整张图上 |
| —— | 影子、光环、三色主题着色 |

所以：

- **不要让 AI 生成动图/序列帧**。循环一致性是 AIGC 最差的一环，而引擎本来就会给静态图加上呼吸和过渡。
- **不要在图里画影子**。影子是独立一层，要跟着位姿缩放才有重量。图必须透明底。
- **不要在图里画状态标记**（感叹号、汗滴、zzz）。这些引擎可以叠，画进去会和三色主题打架。

## 1. 2D 形态（`kind: "frames"`）

### 画布与定位

| 项 | 要求 | 为什么 |
|---|---|---|
| 尺寸 | **1024 × 1024** | 2 倍 Retina 下折叠态显示 132px，1024 足够且有裁切余量 |
| 格式 | **PNG 或 WebP，带 alpha 透明底** | 桌宠是透明窗口，不透明底会出现一个方块 |
| 角色朝向 | 正面或四分之三侧面，**八张必须一致** | 过渡是交叉淡入，朝向跳变会看出来 |
| 水平位置 | 角色**中线对齐画布中线** | |
| 垂直位置 | **脚底落在画布高度 94% 处** | 引擎的转轴设在 50%/94%（脚跟），瘫倒才像倒而不是原地转 |
| 角色占比 | 高度占画布 **75%~80%** | 留出举奏折、跳起、歪头的余量，否则会被裁 |
| 边缘 | 四周至少留 **60px** 空白 | 位姿插值会让图轻微超出原位 |

### 八张图清单

命名固定，引擎按名字取：

| 文件名 | 状态 | 要传达的**肢体**信息（表情是次要的） |
|---|---|---|
| `idle.webp` | 待命 | 站直、放松、无事可做 |
| `running.webp` | 运行中 | 明显前倾、专注、手在忙 |
| `awaiting_grant.webp` | 请奏 | **双手把东西端起来递向观者**，身体略前倾。这是最重要的一张，要一眼看出「它在等你」 |
| `awaiting_choice.webp` | 请择 | 两手向两侧摊开、头微侧，呈现「有两条路」 |
| `done.webp` | 复奏 | 轻微跃起、放松愉快、把成果呈上 |
| `stale.webp` | 久候 | 姿势垮下来、重心下沉、疲态。和 `awaiting_grant` 应是同一动作的「累版」 |
| `exiting.webp` | 请退 | 深鞠躬 / 抱拳告退 |
| `limp.webp` | 瘫 | **横躺或整体倾倒**，四肢摊开 |

> 差异判据：把八张图缩到 48px 并排看，如果分不清哪张是哪个状态，就是**肢体差异不够大**，要重做而不是靠加表情补。这条是你文档里「状态差异特大」的落地检查方式。

### 一致性怎么做（AIGC 最容易翻车的地方）

八张图必须像同一个角色、同一台相机、同一套光。推荐流程：

1. 先只生成 `idle.webp`，反复调到满意，作为**参考图**。
2. 其余七张全部用**参考图驱动**生成（img2img / reference image / character reference），提示词里只改动作描述，画风、配色、光照、相机描述**逐字复制**。
3. 生成后逐张核对：色板是否漂移、线宽是否变化、头身比是否变化。漂移的重做，不要将就——交叉淡入会把差异放大成「闪」。

提示词里建议固定死这些词：正面视角、平光无投影、纯透明背景、全身入画、扁平厚描边（或你选定的画风）、同一配色。

### 皮肤清单

复制 `src/skins/_frames-template/skin.json`，改名字与配色即可。

```
src/skins/my-skin/
  skin.json
  frames/
    idle.webp  running.webp  awaiting_grant.webp  awaiting_choice.webp
    done.webp  stale.webp    exiting.webp         limp.webp
```

跑 `AICP_SKIN=my-skin npm start`。

调位姿看 `AICP_POSES=1 AICP_SKIN=my-skin npm start`（八态一屏摆开）。

## 2. 3D 形态（`kind: "model3d"`）

渲染管线**尚未接入**，但契约已定，按这个出模型不会白做。当前加载会直接抛错并打印契约，不会静默给个占位方块。

| 项 | 要求 |
|---|---|
| 格式 | **GLB**（或 VRM，若要复用 VTuber 生态） |
| 坐标 | **Y 轴朝上**，单位米，角色脚底在 y=0，面朝 +Z |
| 高度 | 0.8~1.2 米（等比缩放由引擎处理） |
| 动画 | 每个状态一个**循环动画片段**，片段名写进 `skin.states[x].clip` |
| 过渡 | 引擎用 `AnimationMixer.crossFadeTo(state.in.ms)` 做片段间融合，你**不需要**做过渡动画 |
| 面数 | 建议 2 万三角面以内（常驻进程，不能吃满 GPU） |
| 贴图 | 单套 PBR，2048 以内 |

接入前还需把 three.js 落到本地依赖——CSP 是 `script-src 'self'`，不能走 CDN。

## 3. 位姿表：让静态图动起来

`skin.json` 的 `states[x].pose` 作用在两个图层上：`figure`（整张图）与 `shadow`（影子）。
即使八张图全是静态的，把位姿调好之后观感差别很大。

可调属性（都会被插值）：

| 键 | 含义 | 常用范围 |
|---|---|---|
| `x` / `y` | 平移，px | -30 ~ 30 |
| `r` | 旋转，度（绕脚跟） | -90 ~ 20 |
| `s` | 整体缩放 | 0.9 ~ 1.1 |
| `sx` / `sy` | 分轴缩放 | 0.9 ~ 1.1 |
| `o` | 不透明度 | 0 ~ 1 |

`in.ms` 是**进入该状态的过渡时长**，`in.easing` 收 CSS `cubic-bezier(...)`，第二个控制点的 y 可以大于 1 来做回弹。
经验值：请奏要**快而弹**（280ms + 过冲），瘫要**慢**（1100ms + 缓入），久候要**慢慢垮**（760ms）。

`loops` 描述待机循环，关键帧沿一个周期均匀分布，段内自动 sine 缓动，首尾闭合。

## 4. 验收清单

- [ ] 八张图缩到 48px 仍能分辨状态
- [ ] 透明底，没有自带影子
- [ ] 脚底都落在 94% 基准线上，切换时角色不会上下跳
- [ ] 配色/线宽/头身比在八张之间无漂移
- [ ] `AICP_POSES=1` 检查台里八格差异明显
- [ ] 实际跑一遍 demo，看 `请奏 → 复奏` 与 `复奏 → 请退 → 瘫` 两条链的过渡不闪
